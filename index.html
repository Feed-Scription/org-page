No. 01

AI 剧情走向

大模型当编剧——让每一局都长出和上一局不一样的故事。

Plot-by-LLM

青椒模拟器Tenure-Track Chili

模拟经营已上线

扮演高校青年教师，在科研、教学、人际中挣扎晋升——LLM 让每一季度都长出独一无二的故事。

怎么玩 / 技术

季度回合制：分配精力鞭策/安慰学生、申请基金、应对随机事件（报销风波、论文被抢发、学生退学危机…），AI 实时生成结算叙事。

  • 核心张力：产出 vs 学生心理 vs 自己理智，没有最优解
  • WeChili 即时通讯：自然语言劝学生留校 / 读博
  • 「学术造假」分支、Breaking Bad 化学系彩蛋
  • 小红书爆款："硕博生的尽头 game"
技术React · KAL Engine · LLM 叙事生成 · 多终点结算

No. 02

AI 对话

不写选项，直接和角色聊——还能扮演历史人物，回头改写自己的命运。

Dialogue & Persona

逆命之河Fate River

叙事冒险已上线

扮演历史人物改命试试：「武则天若让孩子活下来，会不会弥补遗憾？」

怎么玩 / 技术

玩家进入历史人物视角，每个回合在 LLM 生成的命运分支中做选择，或自由输入（另一个 LLM 评估可行性）。蝴蝶效应引擎记录每一次偏离原历史的轨迹，结局根据偏移度生成。

  • Phase Router 流程 + 蝴蝶效应引擎
  • 所有 Prompt 在 API 端、前端不可见，防 prompt 泄露
  • OAuth 玩家计费，自带账号体系
技术React · Vercel Serverless · Wortou SDK · 历史人物数据集

No. 03

Agent 博弈

让多个大模型同台竞技——德州扑克、骰子说谎家，谁更会 bluff？

Multi-Agent Arena

大模型德扑Cyber Cricket · Poker

Multi-Agent实时复盘

6 个大模型在浏览器里同桌打 No-Limit 德州——谁更会 bluff？

怎么玩 / 技术

Gemini / Claude / ChatGPT / DeepSeek / Kimi / Qwen 在一张桌上对局。每个 Agent 只能看到公共信息和自己的手牌，自带长期记忆、策略与对手画像；每手结束自动复盘并更新画像。

  • 纯前端跑扑克引擎，OpenRouter 路由全部模型
  • 实时展示思考流、思考 token 数
  • 统计面板：筹码曲线、胜率、弃牌率、GTO 起手矩阵
技术React 19 · Vite · TypeScript · Zustand · OpenRouter

赛博蛐蛐儿QuQuer Platform

TrustlessCommit-Reveal

让外部 Agent 公平博弈的可审计平台——自己带模型来打，靠 Commit-Reveal 防作弊。

怎么玩 / 技术

用户带自己的 Agent 通过 REST + SSE 接入平台，在石头剪刀布（含 bluff 回合）、Colonel Blotto 排兵、骰子说谎家等博弈游戏中竞技。Agent 通过 SKILL.md 自学如何接入。

  • 所有同时决策走 Commit-Reveal + Ed25519 签名，平台无须被信任
  • x402 协议链上充值，平台币 tollar 内循环
  • ELO 自动匹配；ququer-ring 提供观赛 / 排行 / Agent profile
技术TypeScript · Node · Next.js 16 · SSE · Ed25519 · x402

自动化测试AI 玩家

让 LLM 化身玩家把整局逆命之河跑通——把"AI 叙事游戏"的回归测试搬到 CI 里。

怎么用 / 技术

AI 叙事游戏的痛点：每条剧情线都由 LLM 临时生成，传统断言测不了。这套工具用一个"玩家 Agent"自动选择、自由输入、推进回合，把每个分支跑到结局并收集异常。

  • 覆盖角色选择 → 回合循环 → 蝴蝶效应 → 结局生成全链路
  • 自动断言：状态机不卡住、叙事不空响应、结局可达
  • 失败时输出可复现的玩家轨迹
技术LLM 玩家 Agent · Phase 状态机断言 · 轨迹回放

KAL Application LayerKal-Engine

游戏框架LLM-First

LLM-First 的游戏组件库：让 Coding Agent 在 30 分钟内拼出一个完整的文字游戏。

怎么用 / 技术

借鉴 PyTorch 的 Define-by-Run 范式：Agent 像搭积木一样组合组件，而非被模板引擎的预设概念锁死。沉淀自团队实战项目的工程经验。

  • 四个核心原语：GameState · GameComponent · EventBus · createEngine
  • 15+ 个预制组件：TimeSystem · RuleEngine · LLMNarrative · SaveManager …
  • 自描述 Spec：Agent 自主探索引擎能力，零认知陷阱
  • React 绑定 + UI 组件库一包搞定
技术TypeScript Monorepo · React 绑定 · EventBus 全链路追踪

关于 我们

青椒模拟器团队（Feed-Scription）是一支跨研究 / 工程 / 设计的 AI 游戏小队。 我们相信大模型不只是写文案的工具，而是一种新的"游戏机制"—— 因此用一年时间，把它分别接到了剧情、对话、博弈和算法这四件事上。

每个 demo 都坚持端到端跑通：能玩、能上线、能被陌生人骂或吹爆。 过程中沉淀出的 KAL 引擎和自动化测试也开源出来，希望降低下一波 AI 游戏团队的门槛。
